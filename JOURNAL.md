## 2026-11-14 - Installation de Node.js

- **Décision** : installer Node.js avec le dépôt NodeSource et apt.
- **Autres possibilités** : le paquet nodejs d'Ubuntu, le site nodejs.org.
- **Raison** : NodeSource donne la version LTS récente, et les commandes sont dans mon README pour être refaites à l'identique.

## 2026-11-14 - Système pour le terminal

- **Décision** : utiliser le terminal Linux (Bash).
- **Autres possibilités** : Zsh, Fish ou PowerShell.
- **Raison** : Bash est installé par défaut sur de nombreuses distributions Linux. Il permet d'exécuter des commandes nécessaires pour gérer les fichiers, installer des logiciels et travailler avec Git et Node.js.
